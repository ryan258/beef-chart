# Architecture and current behavior

**English** · [Español (Argentina)](architecture.es.md)

Beef Chart is a zero-build static page combining a Bauhaus layout, vintage halftone artwork, interactive cut-paper cow maps, and D3 charts. It is an educational atlas and stored retail-context reference. Most frontend logic remains inline in `index.html`; `assets/bauhaus.css` supplies the active palette, layout, diagram styling, and responsive reader rules.

## Runtime boundaries

1. Embedded cut/primal records populate the full cut directory and search independently of D3.
2. Cow maps are progressive enhancement: 20 Argentine controls and nine U.S. region controls. Their paths expose names and Enter/Space activation; hover and focus update a full-name readout and highlight related regions across both maps. The directory provides a complete alternative.
3. Each chart checks its own dependencies. Missing Sankey affects the flow only. Missing D3 leaves search, dossiers, price text, and tables usable.
4. Startup loads `data/prices.json` and `data/manual-prices.json` independently, with eight-second request limits and `cache: 'no-store'`. The automatic snapshot passes the v2 contract before a manual overlay can be applied. `assets/manual-prices.js` skips unfinished date/price rows and validates completed quotes; an invalid manual file shows a warning and leaves automatic prices available. Loading, ready and unavailable are distinct automatic-data states. `acceptPrices` refreshes cards/tables and the active dossier; `refreshActiveModal` restores a recreated focused control and scroll position. Invalid automatic evidence makes price data unavailable while the atlas remains usable. A ready snapshot without an observation has a separate missing state.
5. `FLOW_NODES`/`FLOW_LINKS` and `VALUE_MODEL` power both diagrams and tables. Flow totals 100 illustrative teaching units; the value model is fixed illustrative retail allocation. Neither is measured carcass yield or current valuation.
6. A native `<dialog>` isolates the background and handles the modal lifecycle. Button, Escape, and backdrop share close handling; each dossier has a visible/accessible title. Navigation inside a primal retains the original initiating focus for return.
7. At 600px and below, dense flow/price charts give way to readable table views. A shared media query opens tables at startup or when entering that width; manual choices persist while remaining within the same width range. Dossiers stack their content and price evidence. Tables carry source/status/FX qualification; the radar has its own heuristic-score table.
8. Stored organ observations (*mollejas*, *riñón*, *lengua*) with `unit_scale_unverified: true` have their comparison and card prices withheld ("Price withheld") while retaining their amounts solely as "Stored evidence only" with explicit lineage notice.
9. Optional catalog `sampling` evidence is validated in both Python and JavaScript. `samplingContext` supplies the same bounded-sample explanation to dossiers and the price table, including unknown historical coverage when the metadata is absent.

10. `ar_sources` retains independent IPCVA, INDEC and Carrefour observations; the automatic `ar` view prefers IPCVA, then INDEC, then Carrefour. `carrefour_originals` preserves the initial retailer records exactly. Manual quotes replace only the in-memory display selection, with overridden automatic records retained under `manual_originals`; neither source file, ledger nor archive is rewritten.
11. All 24 dossiers appear in the coverage table. Country-level missing, retained, withheld, native-only and manual states are explicit. Bola de lomo uses its own IPCVA key; the existing U.S. round-roast series remains a qualified generic reference. Card and dossier views show missing sides instead of borrowing another cut's price.
12. Retained chart points are hollow and labeled with an asterisk, with dashed connecting lines. Manual USD/lb points carry a dagger; manual ARS/kg quotes stay native and are omitted from USD-only points. Maps and images are labeled as illustrations; flow/value inputs are fixed teaching allocations and radar traits are editorial scores.

Search is accent-insensitive and operates on names, aliases, and IDs. `CUT_SEARCH_INDEX` includes English and Spanish equivalents independently of the display language, so toggling the interface does not change the result set for an unchanged query. One result opens; ambiguous matches show choices; missing/empty queries explain recovery. Primal actions open an actual primal explanation rather than an arbitrary retail cut. Popular-card previous/next actions synchronize with the selected featured cut.

The v1 reference helpers in `assets/reference-tools.js` create `?cut=<catalog-id>&lang=<language>` links, validate optional `beef-chart-last-cut` browser storage and format plain-text butcher notes. Opening a dossier replaces the URL's cut state; closing it clears that parameter. A direct valid link opens the cut, while an unknown ID leaves search available with feedback. Resume is an explicit button, and denied storage leaves current-session lookup and copyable links usable. Notes reuse catalog guidance and selected valid manual quote amounts/units/dates without conversion; automatic observations and withheld organ evidence are not copied as quotes. Readonly text fields use `.value`; clipboard denial selects the text for ordinary copying. Dossier refresh preserves focus and scroll, including its note field.

`assets/snapshot-summary.js` derives the compact snapshot card summary from selected automatic observations and automatic originals beneath manual overrides. Source periods and USDA window conventions remain distinct from metadata assembly. The detailed source/attempt explanation lives under Sources and methods. Compare navigates to prices, and Read Value Shares opens its actual table.

## Languages

Dynamic renderers call `t()` on copy or tagged templates at the display boundary. Canonical cut IDs, U.S. region names, price records, validation, and comparison logic stay language-independent; interpolated upstream evidence is still escaped in HTML.

English is the default. The `English / Castellano porteño` buttons switch in place, update `html[lang]` and pressed states, and rerender the directories, maps, charts, tables and current search without re-fetching prices. Expanded sections and input values persist. `?lang=en` or `?lang=es-AR` overrides the optional `beef-chart-language` browser preference; toggling updates that parameter while preserving other parameters and the fragment. Restricted storage does not prevent URL selection or toggling. Spanish uses voseo and occasional local phrasing, with factual and evidence qualifications kept explicit. All 24 descriptions and nine U.S. region explanations are translated; U.S. terms remain cross-reference names, not newly asserted cut equivalences.

The preview allowlist includes `assets/*.js`. Translation, HTML and CSS edits still require restarting the copied preview. Manual-price edits use the live route and need only saving and reloading. The focused language and harmony UI tests cover preference precedence, storage denial, all catalog descriptions, interpolation, evidence escaping, numeric formatting, and price/validator independence. Browser checks cover switching, search, mobile layout, dialog use and chart fallback; they do not establish native-speaker or assistive-technology acceptance.

Anchor navigation uses the measured sticky-header height plus 12px, updated by `ResizeObserver` with a window-resize fallback. Controls on the blue search panel use a contrasting gold focus outline; the white input/button container uses an ink outline. `assets/i18n.js` owns translation and number/tick-format helpers; `usd` and `monthLabel` remain inline. Numeric table cells, teaching shares, benchmark percentages, native prices and FX use locale formatting without mutating evidence. Native amounts and FX use up to six fraction digits consistently across tables, dossiers, fallbacks and retained evidence; USD prices use two decimals and benchmark percentages use one. Reference dialogs rerender from canonical content: primal dialogs regenerate from their records, and the Other-value explanation keeps its English source strings until render, so language changes can restore English.

## Data operations

`fetch-prices.sh` invokes `scrape-retail.py --official`. The standard-library `official_prices.py` module attempts BLS, monthly FX and INDEC independently with the existing endpoints and series, validates each source before merging, and reports source status and complete configured-series coverage. Missing/failed sources retain original evidence; valid INDEC native observations can advance without a USD conversion when matching monthly FX is unavailable. The existing independent daily-FX, catalog-cut and USDA attempts still run after official failures. Retail transport errors include `HTTPException` subclasses such as `IncompleteRead`; nested catalog shapes classify as `ValueError`. Each catalog/USDA batch passes the existing snapshot contract before merge. One final validated atomic write promotes the combined result; partial/empty/error official results and retail error/no-match outcomes produce a nonzero process exit after promotion. Carrefour aggregate states distinguish `ok`, `no_match`, `partial`, `error` and `partial_error`, with requested-cut coverage. The HTTP response closes even when reading fails. Targeted catalog refreshes and the internal local `--official-snapshot` import remain supported. The latter validates source groups independently but still runs retail network attempts.

`ipcva_prices.py` reads 22 AMBA monthly beef rows, while `bcra_fx.py` supplies matching monthly means of direct BCRA USD quotes for IPCVA only. These are distinct from the existing valuation rates used by INDEC/catalog records. `--ipcva-only` and `--usda-only` isolate those refreshes; neither is combined with `--cuts` or the wrapper's `--official` flag. Expected partial refreshes save healthy evidence, print source-level diagnostics and exit nonzero without a programming-error traceback.

The USDA adapter parses the October 9 report's explicit advertisement-ending window (October 3–15), reads the national CW/PW/PY table and avoids the release-page request when dates are printed. PDF/text fixtures are retained. Prior numeric values are not assigned guessed dates. Unrecognized layouts/dates fail with the previous evidence retained; publication, advertisement-ending dates and individual offer dates remain distinct.

`price_contract.py` supplies the minimal v2 qualification/validation/merge/atomic-write boundary. A replaced record retains one previous observation; empty matches and errors keep the original number/date with an inactive/failure qualification. This is bounded recovery, not a complete immutable history database. Source and cut attempt statuses are distinct from observation/retrieval/publication dates.

`serve.sh` copies the index, allowed JavaScript/CSS/images and automatic snapshot into a temporary public directory, then runs `serve_public.py` on `127.0.0.1`. Only `/data/manual-prices.json` is read directly from the project on every GET/HEAD request. It has `Cache-Control: no-store`, observes atomic editor replacements and supplies empty arrays when absent. The live opener rejects symlink/nonregular files and a symlink data directory, and caps reads at 256 KiB. The repository root, reports, credentials, source receipts, optional BeefAPI cache and unused manual template are not served. Other public files remain copied and need a restart after edits. A pre-update running server needs one restart to adopt the live route.

The active manual file has ten prefilled ARS/kg rows; only date and numeric price need to be filled. Null, omitted or blank date/price fields are drafts and do not displace automatic observations. Completed invalid rows and malformed structures reject the overlay with a visible warning. Latest date wins per canonical market/key; later rows revise equal-date entries. Manual ARS prices get no inherited FX. See [the entry guide](manual-prices.md). `fetch-beef.sh` remains optional archival enrichment, not a visible glossary dependency.
